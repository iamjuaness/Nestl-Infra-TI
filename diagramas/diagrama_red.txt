================================================================================
                         SEGMENTACIÓN DE RED (VLANs)
================================================================================

VLAN 10 - FRONTEND (Pública/DMZ)
  Propósito: Servicios expuestos a internet
  Subred: 172.20.10.0/24
  Gateway: 172.20.10.1
  Servicios: Nginx LB, Web servers
  Política: Acceso desde internet solo a puertos 80/443

VLAN 20 - BACKEND (Privada)
  Propósito: Comunicación interna entre servicios
  Subred: 172.20.20.0/24
  Gateway: 172.20.20.1
  Servicios: Base de datos, archivos, NTP
  Política: Solo acceso desde VLAN 10 y 30

VLAN 30 - MANAGEMENT (Administración)
  Propósito: Acceso administrativo y monitoreo
  Subred: 172.20.30.0/24
  Gateway: 172.20.30.1
  Servicios: SSH bastion, Prometheus, Grafana
  Política: Solo acceso desde IPs administrativas

================================================================================
                         FLUJO DE TRÁFICO
================================================================================

1. USUARIO -> https://nestle.local
   -> Nginx LB (VLAN 10) 
   -> Web Primary o Secondary (VLAN 10)
   -> MySQL Primary (VLAN 20)
   <- Respuesta al usuario

2. ADMIN -> ssh -p 2222 bastion.nestle.local
   -> SSH Bastion (VLAN 30)
   -> Acceso a servicios internos

3. MONITOREO -> http://prometheus:9090
   -> Prometheus (VLAN 30)
   -> Métricas de todos los servicios
   -> Grafana visualiza datos

4. BACKUP -> 2:00 AM diario
   -> Script backup_nestle.sh
   -> MySQL dump + web files + configs + logs
   -> Almacenamiento en /backup/nestle/
